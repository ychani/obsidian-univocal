# Univocal Read Aloud (Obsidian plugin)

Read notes aloud with [Univocal](https://univocalapp.com) and highlight each word as it's spoken.

> Work in progress. Desktop (macOS) only; requires the Univocal app.

## Development

```sh
pnpm install
pnpm dev        # watch build → main.js
pnpm build      # typecheck + production build
pnpm typecheck
pnpm test       # vitest
```
